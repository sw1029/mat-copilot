## 1. 개요 (Overview)
초기 유저 의도 정보가 주어진 경우 agent 기반 하위 질문 n개 생성 -> 각 질문별 하위질문 branch를 모호한 점이 해결될 때까지 지속 생성하여 모호한 유저 의도를 구체화한 뒤, 제공된 링크/파일의 결과물을 토대로 해당 초기 의도가 충족되었는지, 얼마나, 어느 지점에서 어긋났는지 확인 후 정량적 통계 생성 및 정성/정량 보고서 반환

## 2. 배경 및 문제 정의 (Background & Problem)
- 현재 상황: 유저 초기 의도는 모호하며, 초기 설계가 미흡하거나, 초기 설계를 원활히 수행하였더라도 ai에게 위임하는 경우 문서작업, 코딩, 기타 작업 등에서 발생하는 초기 의도와 다른 실수(의도되지 않은) 및 ai에게 작업을 위임한 경우 발생하는 할루시네이션 등을 사용자가 한 눈에 파악하기 힘들다. 
- 해결하려는 문제: 유저 초기 의도를 반복된 질의(deep interview)를 통해 상세 구체화 및 반복되는 질의에서 유형/무형적으로 확인 가능한 의식적/무의식적 유저의 의도를 추출하여 해당 의도 대비 유저가 제공한 결과물(문서, 작업 결과물, 코딩 결과물 등)가 얼마나 어긋난 형태인지 상세 보고하고, 해당 결과를 바탕으로 개선제안
