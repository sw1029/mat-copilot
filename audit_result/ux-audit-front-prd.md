## 1. 총평

접근성·오류 복구·상태 투명성이 매우 잘 정의된 수준 높은 PRD. 다만 결과 화면 레이아웃 비율과 인터뷰 세션 복구 범위 등 아키텍처에 영향을 주는 High 이슈 3건은 TRD 확정 전에 결정이 필요하다.

## 2. 강점

- **인지 부하 설계 우수**: "한 번에 하나의 질문"(G2, FR-5), 미도착 질문 비표시(§6.2)가 일관됨
- **오류 UX 성숙**: 입력값 보존(§8.2), 실패 단계만 재시도(§6.3), 가짜 진행률 금지(§6.3 — 임의 백분율 대신 단계형 로더) 명시
- **접근성**: 색각 이상 대응(§12 리스크 + AC-12), 키보드 전용 흐름(AC-15), `산정 불가` vs 0점 구분(§6.4)이 구체적

## 3. 발견 사항

### 🔴 High (3건)

#### H-1. 결과 화면 좌측 30%에 문서 2개는 가독성 위험
- 최소 해상도 1280px 기준 좌측 30% ≈ 384px, PRD·TRD 세로 50:50 분할 시 각 문서 약 384×330px
- Markdown 문서(제목 계층, 표, 코드)를 읽고 각주를 탐색하기에 협소
- 핵심 가치가 "문서 근거 확인"(G6, US-5)인데 근거 열람 공간이 가장 작음
- **권장**: 패널 비율 사용자 조절(스플리터), 문서 패널 확대/전체보기 모드, 또는 좌우 비율 재검토. 최소한 Open Questions에 추가

#### H-2. 인터뷰 이탈/중단 시 복구 시나리오 부재
- FR-10은 "생성 작업" 복구만 다룸. 인터뷰 도중 새로고침·브라우저 종료 시 답변 복구 여부 미정의
- 질문이 수십 개일 수 있는 구조(G3)에서 중간 유실은 치명적 이탈 요인
- AC-7("진행 중 작업 복구")이 인터뷰 단계를 포함하는지 모호
- **권장**: 인터뷰 세션 복구를 FR로 명시하거나 비목표로 선언

#### H-3. 인터뷰 종료 시점 예측 불가
- 질문 개수 무제한(G3)인데 "얼마나 남았는지" 알려주는 장치 부재
- 끝이 안 보이는 질문 흐름은 인터뷰 완료율 목표(70%)를 직접 위협
- **권장**: 대략적 진행 단계 표시, 예상 남은 질문 수, 또는 "지금까지 답변으로 문서 생성하기" 조기 종료 옵션 검토

### 🟡 Medium (5건)

#### M-1. 캔버스 드래그 UI의 발견 가능성(discoverability) 미정의
- "챗봇 영역만 드래그 가능"은 일반 관례가 아니어서 첫 사용자가 인지하지 못할 가능성 높음 — G1(학습 없이 사용)과 상충
- 힌트/코치마크, grab 커서, 드래그 가능 영역의 시각적 어포던스 정의 필요

#### M-2. 자동 캔버스 이동과 사용자 드래그의 충돌
- §6.2 "새 질문 활성화 시 자동 위치 보정"이 사용자가 이전 질문을 읽으려 드래그하던 중 발생하면 컨텍스트를 빼앗음
- "사용자 조작 중에는 자동 이동 보류" 규칙 필요

#### M-3. 상세 리포트 30% 높이 vs 8개 정보 항목
- §6.4 하부 30%(1280×720 기준 약 200px 미만)에 각주·상태·요약·근거·영향·인용문 2개·개선 제안·신뢰도를 모두 배치하면 대부분 스크롤 뒤에 숨음
- "탐색 시간 중앙값 10초 이내" 목표(§10)와 충돌 — 정보 우선순위(접힘/펼침) 또는 패널 확장 정의 필요

#### M-4. 각주 번호만으로는 문서 전체 스캔이 어려움
- 각주 번호는 대응 관계 식별엔 좋으나, "심각한 차이가 어디에 몇 개인지" 훑어보는 수단 부재
- 차이 목록(index) 뷰 또는 스크롤바 마커 등 개요 장치 검토 권장

#### M-5. 홈 이동 = 작업 포기?
- §5.1 이탈 확인 모달 후 "초기 화면으로 이동"이 세션 폐기인지, 복귀 가능한지 미정의
- §11.2 가정("동일 세션 ID로 재접근 가능")과 연결되는 UX(세션 목록, URL 공유 등) 부재

### 🟢 Low (5건)

- **L-1.** §6.1 "단축키로 제출": Enter=제출/Shift+Enter=줄바꿈 등 구체 규칙 미정 — 여러 줄 입력과 얽힌 UX 결정 사항
- **L-2.** 답변 길이 제한/글자 수 카운터 미정의 — 유효성 안내(§6.1)와 연결됨
- **L-3.** 성공 지표(§10)에 "인터뷰 소요 시간"·"세션당 평균 질문 수" 부재 — 이탈 원인 진단에 필수
- **L-4.** 다크 모드/테마 언급 없음 — 비목표로라도 명시 권장
- **L-5.** Open Questions 10번(최소 해상도 미만 처리)은 M4 이전 결정 필요하나 의사결정 기한/담당 없음

## 4. 요약
